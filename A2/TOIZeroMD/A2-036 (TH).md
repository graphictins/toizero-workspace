ข้อสอบ สําหรับ โครงการ   TOI - Zero   การฝึก เขียนโปรแกรมบนแพลตฟอร์ม   TOI National Grader  เพื่อใช้สําหรับสมัครสอบคัดเลือกเข้าค่าย 1 สอวน.  ออกโจทย์โดย สุพรชัย เทียมทองอ่อน   โรงเรียน บดินทรเดชา (สิงห์ สิงหเสนี)  Arcade of Time   –   Store Check  ในย่านชุมชนใจกลางเมือง ที่เต็มไปด้วยผู้คนและสีสันแห่งชีวิต มีร้านค้าหลากหลายสไตล์ ทั้งร้านอาหาร  คาเฟ่ และร้านเกมที่เปิด – ปิดในเวลาต่างกันไป แต่ละร้านมีตารางเวลาเฉพาะตัว บางร้านเปิดเช้าปิดบ่าย บางร้าน  เปิดสายปิดดึก นัท เป็นวัยรุ่นที่ชอบเดินเล่นในย่านนี้ทุกวัน เขาอยากรู้ว่า   “ ในเวลาที่เขาเดินผ่านแต่ละช่วง จะมีร้าน  ที่ยังเปิดอยู่กี่ร้าน ”   เพื่อจะได้เลือกเส้นทางที่มีร้านเปิดเยอะที่สุด ดูคึกคักที่สุด  จงเขียนโปรแกรมรับ จํานวนร้านค้า เป็นจํานวนเต็ม และเวลาที่ต้องการตรวจสอบ (นาที) เป็นจํานวนเต็ม คั่นด้วย  เว้นวรรค และบรร  -   ข้อมูลที่คุณได้รับคือเวลาที่ร้าน เปิด ( start)   และ ปิด ( stop)   ของทุกร้าน โดยเวลานับเป็นนาที ตั้งแต่   0   ถึง   1440  ( เท่ากับ   24   ชั่วโมงของ   1   วัน)  -   ณ เวลาใดเวลาหนึ่ง จะมีร้านเปิดอยู่ทั้งหมดกี่ร้าน ?  เงื่อนไขข้อมูล ( Constraints)   ที่เหมาะสม  • 1 ≤ num ≤ 10 0,000  ( จํานวนร้านค้ามีได้มากสุดแสนร้าน)  • 1 ≤ query ≤ 10 000  ( จํานวนเวลาที่ต้องตรวจสอบได้มากสุดแสนครั้ง)  • 0 ≤ start < stop ≤ 1440  ( เวลาเปิดและปิดนับเป็นนาที ภายใน   1   วัน =   24   ชั่วโมง =   1440   นาที)  •   เวลาที่ใช้ตรวจสอบ (แต่ละค่าใน   query)   ต้องอยู่ในช่วง   0 ≤ k ≤ 1440  •   ข้อมูลเป็นจํานวนเต็มทั้งหมด  ข้อมูลเข้า :   บรรทัดแรก: จํานวนเต็ม 2 ค่า   num   และ   query ( จํานวนร้าน และ จํานวนเวลาที่ต้องการตรวจสอบ)  บรรทัดถัดไป   num   บรรทัด: แต่ละบรรทัดประกอบด้วย   start stop ( เวลาเปิดและเวลาปิดของแต่ละ  ร้าน)  บรรทัดสุดท้ายการป้อน   query   ค่า เป็นเวลาที่ต้องการตรวจสอบ คั่นด้วยช่องว่าง ตามจํานวนที่   query  ในบรรทัดแรก  ผลลัพธ์ :   พิมพ์ผลลัพธ์   query   ค่า แต่ละค่าคือจํานวนร้านที่เปิดอยู่ในเวลานั้น ๆ โดยพิมพ์ต่อกันในบรรทัดเดียว  คั่นด้วยช่องว่าง  ตัวอย่าง :
