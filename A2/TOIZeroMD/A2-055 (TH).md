ข้อสอบ สําหรับ โครงการ   TOI - Zero   การฝึก เขียนโปรแกรมบนแพลตฟอร์ม   TOI National Grader  เพื่อใช้สําหรับสมัครสอบคัดเลือกเข้าค่าย 1 สอวน.  ออกโจทย์โดย นายธนวิชญ์ สิงคะปะ   โรงเรียน พิริยาลัยจังหวัดแพร่  สถิติคลื่นความร้อน ( Heatwave Stats)  ให้รับจํานวนเต็ม   N   และอุณหภูมิสูงสุดรายวันจํานวน   N   ค่า (หน่วย   °C)   แล้วแสดงสถิติดังนี้:  SUM, AVG, MEDIAN, MAX, MIN, ALERT,   และ   SORTED  นิยาม:  SUM =   ผลรวมของอุณหภูมิทั้งหมด  AVG =   ค่าเฉลี่ย =   SUM / N  MEDIAN =   ค่ามัธยฐานหลังเรียงข้อมูลจากน้อยไปมาก  •   ถ้า   N   เป็นเลขคี่: ใช้ค่าตัวกลาง  •   ถ้า   N   เป็นเลขคู่: ใช้ค่าเฉลี่ยของ 2 ค่ากลาง  MAX =   ค่ามากที่สุด  MIN =   ค่าน้อยที่สุด  ALERT =   จํานวนวันที่มีอุณหภูมิ   > =   37  SORTED =   อุณหภูมิทั้งหมดเรียงจากน้อยไปมาก  การแสดงผลตัวเลข:  SUM, AVG, MEDIAN, MAX, MIN   และค่าทั้งหมดใน   SORTED   ต้องแสดงเป็นทศนิยม 2 ตําแหน่งเสมอ (ปัดเศษ  ตามหลักคณิตศาสตร์)  ข้อมูลเข้า :   มี 2 บรรทัด  บรรทัด ที่ 1:   เป็นจํานวนเต็ม   N ( 1   ≤ N ≤   1000)  บรรทัดที่   2:   เป็นจํานวนจริง   N   ค่าแต่ละค่าคั่นด้วช่องว่าง  ผ ลลั พธ์ :   มี 7 บรรทัดตามรูปแบบต่อไปนี้:  SUM=<value>  AVG=<value>  MEDIAN=<value>  MAX=<value>  MIN=<value>  ALERT=<count>  SORTED=<v 1 > <v 2 > ... <vN>   โดยค่าใน   SORTED   คั่นด้วยช่องว่าง 1 ช่อง
