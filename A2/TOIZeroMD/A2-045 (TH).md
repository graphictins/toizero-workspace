Blockchain  Blockchain   คือเทคโนโลยีว่าด้วยระบบการเก็บข้อมูล ( Data Structure)   ซึ่งไม่มีตัวกลาง แต่ข้อมูลที่  ได้รับการปกป้องจะถูกแชร์และจัดเก็บเป็นสําเนาไว้ในเครื่องของทุกคนที่ใช้ฐานข้อมูลเดียวกันเสมือนห่วงโซ่  (Chain)   ทุกคนจะรับทราบร่วมกัน ว่าใครเป็นเจ้าของและมีสิทธิในข้อมูลตัวจริง เมื่อมีการอัปเดตข้อมูลใด ๆ   สําเนา  ข้อมูลในฐานเดียวกันก็จะอัปเดตตามไปด้วยทันทีทําให้การปลอมแปลงข้อมูลไม่ใช่เรื่องง่าย เพราะทุกคน   ต้อง  รับทราบและตรวจสอบความถูกต้องของข้อมูลร่วมกันได้อีกทั้งไม่มีระบบล่ม และภัยใด ๆ ก็ไม่อาจทําลายอุปกรณ์  ในระบบได้พร้อมกัน เช่นเดียวกับการถูกแฮ็กข้อมูล ซึ่งต้องทําการแฮ็กทุกเครื่องพร้อ ม ๆ กัน หรืออย่างน้อยต้อง  แฮ็กเครื่องที่ถือสําเนาให้ได้มากกว่า 51% จึงจะแฮ็กได้สําเร็จ เมื่อมีข้อมูลเข้ามาในระบบ มันก็จะถูกกองรวม ๆ กัน  ไว้พอได้จํานวนหนึ่ง ก็จะจัดบรรจุข้อมูลเหล่านั้นลงกล่อง ( Block)   และปิดกล่อง เพื่อป้องกันการแก้ไขข้อมูล  Blockchain   จึงได้เชื่อมโยง   Block   ก่อนหน้า ด้วยค่า   HASH   ของ   Block   ก่อนหน้านั้น แล้วสร้างเป็นค่า   HASH   ใหม่  ของ   Block   นั้น และเชื่อมต่อกันไปเรื่อย ๆ ถ้ามีคนแก้ไขข้อมูลใน   Block   เมื่อเทียบกับค่า   Hash   ใน   Block   ก่อน  หน้าก็จะเห็นว่าไม่ตรงกัน ก็จะรู้ได้ทันทีว่ามีการแก้ไขข้อมูล ดังนั้นภายในแต่ละกล่องจะประกอบด้วย  o   ข้อมูล  o   ค่า   Hash   ของ   Block   ก่อนหน้า ( Previous Hash)  o   ค่า   Hash   ของ   Block  กล่องธุรกรรมใหม่จะถูกสร้างขึ้นเรื่อย ๆ โดยจะเชื่อมและอ้างอิงกับกล่องเก่าอยู่เสมอ และไม่สามารถ  ย้อนกลับไปแก้ข้อมูลใน   Block   ได้ผลก็คือข้อมูลจะถูกเก็บถาวร  จงเขียนโปรแกรม ในการตรวจสอบความถูกต้องของโซ่บล็อก   โดยให้ พิจารณาว่า การอ้างอิงจากบล็อก  ถัดไปถูกต้องหรือไม่ กล่าวคือ หากบล็อกถัดไปอ้างถึงแฮชของบล็อกปัจจุบันถูกต้อง แสดงว่าบล็อกปัจจุบัน   “ ผ่าน ”  โปรแกรมจะต้องตรวจสอบจากบล็อกปัจจุบันย้อนกลับไปยังบล็อกก่อนหน้า และแสดงผลจากบล็อก  ท้ายสุดย้อนกลับไปบล็อกแรก โดยต้องใช้   Recursive Function   ในการประมวลผล/แสดงผล
