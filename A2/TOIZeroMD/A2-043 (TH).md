ข้อสอบ สําหรับ โครงการ   TOI - Zero   การฝึก เขียนโปรแกรมบนแพลตฟอร์ม   TOI National Grader  เพื่อใช้สําหรับสมัครสอบคัดเลือกเข้าค่าย 1 สอวน.  ออกโจทย์โดย นายอาทิตย์ สร้อยสังวาลย์   โรงเรียน สตรีศรีสุริโยทัย  นักสํารวจถํ้า ( Cave Explorer)  “ น้องโค้ด ”   นักผจญภัยมือใหม่ได้ค้นพบถํ้าลึกลับแห่งหนึ่ง ถํ้ามีลักษณะเป็นทางเดินยาวเรียงต่อกันเป็น  เส้นตรง มีทั้งหมด   N   ช่อง (นับจากซ้ายไปขวา)  ในแผนที่ถํ้า แต่ละช่องจะแทนด้วยตัวเลขดังนี้  •   0 =   พื้นที่ว่าง  •   1 =   ตําแหน่งของน้องโค้ด  •   2 =   ตําแหน่งของหีบสมบัติ  น้องโค้ดพบชุดคําสั่งการเคลื่อนที่เป็นสตริง   S   ซึ่งประกอบด้วย:  •   L   หมายถึง เดินไปทางซ้าย   1   ช่อง  •   R   หมายถึง เดินไปทางขวา   1   ช่อง  ให้จําลองการเคลื่อนที่ตามลําดับคําสั่ง และแสดง   “ แผนที่ถํ้าในสถานะสุดท้าย ( Final State)”  เงื่อนไขการเคลื่อนที่  •   หากคําสั่งใดทําให้น้องโค้ดเดินออกนอกขอบเขตถํ้า   ให้ ยกเลิกการเคลื่อนที่ในคําสั่งนั้น และน้องโค้ดจะอยู่  ตําแหน่งเดิม  •   หากน้องโค้ดเดินไปถึงช่องที่มีหีบสมบัติ ( 2)   ให้ถือว่า น้องโค้ดเก็บสมบัติได้ทันที แล้วน้องโค้ดจะหยุดอยู่ที่  ช่องนั้น   ยกเลิกคําสั่งที่เหลือทั้งหมด  ข้อมูลเข้า :   บรรทัดที่   1:   จํานวนเต็ม   N   คือความยาวของถ้ํา  บรรทัดที่   2:   จํานวนเต็ม   N   ตัว คั่นด้วยช่องว่าง แทนแผนที่เริ่มต้นของถ้ํา โดย:  0   แทน พื้นที่ว่าง  1   แทน ตําแหน่งเริ่มต้นของน้องโค้ด  2   แทน ตําแหน่งของหีบสมบัติ  ( ในแผนที่จะมี   1   เพียงหนึ่งตัว และ   2   เพียงหนึ่งตัวเสมอ)  บรรทัดที่   3:   สตริง   S   คือชุดคําสั่งการเคลื่อนที่ ประกอบด้วยตัวอักษร   L   และ   R   เท่านั้น  ข้อจํากัด ( Constraints)  • 3 <= N <= 100  • 1 <=   ความยาวของสตริง   S <= 200
